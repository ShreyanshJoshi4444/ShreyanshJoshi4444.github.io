01 / NLP + DEEP LEARNING2026 — Present

Emotion Prediction

A six-class text classifier taken from model comparison to a public, interactive experience.

16,000 training examples90.35% validation accuracy*
Live demo ↗Code ↗
How it works +

I prepared tokenized, padded text sequences, then compared Simple RNN, LSTM, GRU, and Bidirectional GRU approaches. Class weighting, dropout, and early stopping supported training. I saved the Keras model and tokenizer and connected them to a Streamlit app with live predictions, all six class scores, and model comparison figures.

*Accuracy was measured on a 2,000-example split also used for validation during training; it is not an independent final test.

02 / DATA ANALYTICS2026

Mental Health Signal

A reusable regression pipeline and interactive app built from 5,000 student records.

0.347 test MAE5,000 records
Live demo ↗
How it works +

I cleaned and explored the records, selected social media, study, sleep, activity, and stress features, and built repeatable transformations with Scikit-Learn ColumnTransformer. After comparing and tuning Linear Regression and Random Forest, the selected model reached test R² 0.878 and MAE 0.347 on a 70/30 split. I packaged the pipeline for Streamlit and a FastAPI endpoint.

A portfolio ML project; the score is not a clinical assessment.

03 / COMPUTER VISION2026

FallGuard

Real-time fall detection from video-derived pose features to live inference and overlays.

1,000+ labeled clips3 datasets used
View GitHub ↗
How it works +

The pipeline turns MediaPipe landmarks into temporal features for a PyTorch LSTM classifier. I used weighted loss for class imbalance, subject-level train/test splitting, and cross-dataset testing on URFD. A FastAPI service handles real-time inference with prediction smoothing, paired with a React/HTML skeleton overlay.

02 / My approach
